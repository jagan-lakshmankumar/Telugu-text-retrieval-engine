=== PART C: Index Statistics ===
Wikipedia dataset (100 articles):
  Documents indexed : 100
  Vocabulary size   : 562 terms  (vocabulary.tsv, held in RAM)
  Postings file     : postings.dat (disk, seeked by byte-offset)

Smoke corpus (10 documents):
  Documents indexed : 10
  Vocabulary size   : 64 terms

Index format (postings.dat line example):
  అమలయింది\twiki183:2
  ← term TAB docId:pos0,pos1,...;docId2:pos0,...

Index design:
  * vocabulary.tsv — term, DF, CF, byte-offset, byte-length → loaded into TreeMap<String, Metadata>
  * postings.dat   — seekable flat file; only the needed byte range is read per lookup
  * No third-party libraries; pure JDK 17+
